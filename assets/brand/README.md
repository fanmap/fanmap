# Fan Map brand assets

Approved Option 03 wordmark. Tagline: **Find Your Fanhood.**

- `fan-map-main.png`: black and cardinal wordmark with tagline; transparent PNG for light backgrounds.
- `fan-map-white.png`: white wordmark with tagline; transparent PNG for dark backgrounds.
- `fan-map-pin.png`: cardinal pin with FAN stacked above MAP; transparent PNG.
- `fan-map-white-web.webp`: smaller lossless version used on the website and in the app.
- `fan-map-main.svg`, `fan-map-white.svg`, `fan-map-pin.svg`: scalable SVG paths traced from the approved logo board, with no font dependencies.
- `fan-map-pin-32.png`, `fan-map-pin-48.png`: browser favicon exports.
- `fan-map-pin-180.png`: iOS home-screen icon with dark background.
- `fan-map-pin-192.png`, `fan-map-pin-512.png`: manifest icons.
- `fan-map-social.png`: logo preview for shared website and app links.

The P has a plain letter counter in every version. Keep the pin shape only as the standalone icon. The SVG masters use cardinal #9D2235. Use the SVG files for future exports.
